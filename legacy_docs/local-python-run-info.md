# Local Python Run Info

This page describes the markdown run report generated by the no-Airflow runner.

Primary runner:

- `scripts/run_local_python_no_airflow.py`

## Report location

Default report directory:

- `logs/run-info`

Default filename pattern:

- `local_no_airflow_run_YYYYMMDD_HHMMSS.md`

You can override the directory with:

```powershell
.\.venv\Scripts\python.exe .\scripts\run_local_python_no_airflow.py --as-of-date 2026-07-18 --run-info-dir logs/custom-run-reports
```

## Report fields

Each report contains:

- run timestamp
- started/finished time (UTC)
- total duration in seconds
- `as_of_date`
- `docker_mode`
- whether SourceB transforms were included
- `spark_remote`
- `nessie_uri`
- `python_executable`
- generated `run_id`
- canonical table row counts
- risk output row count for the selected date

## Why this is useful

- Makes each manual run auditable.
- Captures configuration used for the run.
- Preserves row-count checks as lightweight evidence.
- Helps compare results between runs.
